# Скролл мира

Эффект скроллящейся карты в компоненте `TreasuresAndMonsters` реализован через функцию `addCameraDraggingToObject`, которая используется в классе `SimpleHexSpriteGrid`.

## Как работает скролл

1. В классе `SimpleHexSpriteGrid` создается прямоугольный объект `inputRect`, который покрывает всю область сетки
2. Этот объект делается интерактивным и draggable (перетаскиваемым)
3. При создании сетки вызывается функция `addCameraDraggingToObject(inputRect, width, height)`
4. Функция `addCameraDraggingToObject` добавляет обработчик события `GAMEOBJECT_DRAG` к объекту
5. При перетаскивании объекта изменяются значения `camera.scrollX` и `camera.scrollY` главной камеры сцены
6. Значения ограничиваются с помощью `Phaser.Math.Clamp`, чтобы камера не выходила за границы мира
7. Это создает эффект скроллинга карты при перетаскивании мышью

## Технические детали

- Функция `addCameraDraggingToObject` находится в `src/common/phaser-sugar/camera/addCameraDraggingToObject.ts`
- Она изменяет параметры камеры `scrollX` и `scrollY` при событиях перетаскивания
- Порог перетаскивания устанавливается в 16 пикселей, чтобы случайные клики не вызывали скролл
- Также реализована логика отключения кликов во время перетаскивания, чтобы избежать конфликта между скроллом и кликами по карте
